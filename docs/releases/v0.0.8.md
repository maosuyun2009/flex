# flex 0.0.8

Windows 客户端功能更新，汇总 0.0.6 之后的本地验证改动。

## 下载与安装

- `flex-0.0.8-setup.exe`：Windows x64 当前用户安装包，无需管理员权限。
- `flex-0.0.8-windows-x64.exe`：独立程序，需要 Microsoft Visual C++ 2015–2022 x64 runtime。
- `SHA256SUMS.txt`：下载文件校验值。

安装前请关闭 flex 客户端；无需停止 Rex server。安装不会清除已保存的服务器连接和设置。

## 主要更新

### 侧边栏与连接管理
- 统一为 SERVERS → Sessions，常用管理操作收进 `⋯` 菜单。
- 添加服务器支持手动地址或服务端通讯录；通讯录维护放到 Connection 设置页。
- 菜单支持键盘导航、点击外部关闭及滚动，并隔离底层终端输入。
- 增加 session 重命名/排序、服务器编辑/重连/探测、配置重载、Tailscale 管理及客户端信息。

### 终端与输入
- 修复加载服务端 keymap 后普通按键被截断、Windows 文字输入回调不触发的问题。
- 补充 IME 组合状态、提交去重和搜索框输入隔离的回归测试。
- 鼠标按下/释放/拖动、键盘按下/重复/释放与服务端动作按序发送。
- 显示连接与进程状态，修复终端后台任务释放和尺寸 ownership 处理。

### 窗格与浮窗
- 修复分屏方向、多服务器目标及通知/Agent 跳转焦点。
- 工具浮窗显式取得焦点，并处理创建回复与布局更新到达顺序不同的情况。
- tab 内最后一个平铺 Pane 使用 **本地浮动显示**：再次按 `Ctrl+Shift+F` 直接恢复，不创建 shell、Pane 或 tab。标题显示 `local`；其他客户端不共享这次显示变化。
- 多 Pane 恢复只使用当前 tab 的平铺参照，不再跨 tab 或新建 shell 兜底。
- 支持 detached block 发现/恢复、浮层最小化/恢复及关闭确认。

### Rex 集成
- 持久控制连接保留客户端身份、脚本和动作注册；协议协商范围为 API 8–10。
- 服务端动作面板、JSON 参数、逻辑快捷键序列和 key modes。
- 客户端 Lua 脚本显式加载/卸载和 diagnostics。
- Block creator/flavor 发现、创建及信息查看；未知类型显示不支持渲染的占位窗格。
- 默认关闭的远程客户端动作，验证目标并通过原连接返回结果；跨服务器转发仅允许选定的只读操作。

## 验证

- Windows 全工作区单元测试、release 构建及 NSIS 打包。
- 另以隔离 Rex API 10 服务端验证持久身份/脚本/请求应答、session/block/layer 生命周期及工具浮窗焦点；测试不操作用户会话。

## 已知限制

- 中文候选窗及特定输入法/字体的完整交互仍需实机验证，不能将单元测试等同于全部 IME 场景通过。
- 已报告的部分场景“内容未铺满窗口”尚未完成独立定位与修复。
- 本地浮动不跨客户端同步，也不跨应用重启保留；后续服务端分屏/移动会撤销不再适用的本地显示状态。
- 对于已经存在、且当前 tab 无平铺邻居的真实服务端浮窗，Rex API 10 无直接恢复到空平铺层的接口；客户端会提示限制，而不是创建多余 Pane。旧版本已创建的多余 Pane 不会自动删除。
- 物理扫描码快捷键、终端图片、完整 OSC 8、任意插件内容渲染及原生系统通知尚未完整支持。
- 安装包未做 Authenticode 签名，Windows 可能显示未知发布者提示。

更多实现范围见 `docs/rex-client-coverage.md`，本地 SDK 补丁见 `vendor/shrew/README.md`。
