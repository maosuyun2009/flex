# flex 0.0.10

在 0.0.9 本地验证代码基础上的正式发布：右侧文件浏览与 Rex 原生文件传输、pi 同步重绘修复，以及 zoxide 历史目录选择器。

## 下载与安装

- `flex-0.0.10-setup.exe`：Windows x64 当前用户安装包，无需管理员权限。
- `flex-0.0.10-windows-x64.exe`：独立程序，需要 Microsoft Visual C++ 2015–2022 x64 runtime。
- `SHA256SUMS.txt`：文件 SHA-256 校验值。

安装前请关闭 flex。无需停止 Rex server；已保存的连接和设置会保留。

## 新增：右侧文件浏览

- 标题栏右侧图标开关，默认收起；宽度可拖动调整并记忆。
- 跟随当前 Pane，手动浏览位置按 Pane 保留。
- 路径面包屑、返回上级、刷新、隐藏文件开关，以及大小写／全字／正则过滤。
- 参照 Pebrel 的暗色布局、细线图标、圆角搜索框和窄滚动条。
- 大目录截断时明确提示；按名称前缀向服务器重新查询，不冒充完整递归搜索。

## 新增：Rex 原生文件上传／下载

- 协议协商范围提升为 API 8–13，按实际连接和 block 能力开放功能。
- 上传需要 API 11，下载需要 API 13，使用 `rex.data.bytes.v1`。
- 支持普通文件拖入或文件选择器上传，以及另存为下载。
- 顺序传输队列固定原 server／session／Pane；切换标签页不会改投其他终端。
- 上传前固定已验证的普通文件句柄；下载到临时文件，只有完整成功后才原子保存。
- 取消、失败、手动重试、同名覆盖确认，以及关闭应用时的待传输确认。

**上传语义：当前使用 Rex 原生行为。Rex 决定上传文件存放位置，并在整批完成后把路径粘贴到原 Pane。拖入当前浏览目录不代表文件会存入该目录；因此保留上传确认。**

目录递归传输、直接指定远端上传目录、禁止服务端自动粘贴、SFTP 备用传输、远端删除／重命名／编辑和跨重启续传不在本版范围内。

## 修复：pi 滚动时旧内容与新输出混合

- 遵守 DEC 2026 同步重绘，整帧完成前保留上一张完整画面。
- 使用 Ghostty render-hold 回调捕获准确帧边界，处理同包连续帧和跨包输出。
- 超时、断流、进程退出、尺寸变化和快照恢复会释放旧的绘制暂停。
- 添加 pi 渲染器产生的合成滚动数据回放测试。

## 调整：前缀 z 使用历史目录

先按 `Ctrl+Shift+Space`，松开后按 `z`：

- 调用服务端账户的 `zoxide query --list`，使用 fzf 筛选。
- 不再扫描当前目录的文件与子目录；`f` 和 `d` 行为不变。
- 选中后只输入路径，不自动执行 `cd`。
- 缺少 zoxide/fzf 或历史为空时显示说明。需要在服务端账户 shell 中启用 zoxide 来积累访问记录。

## 其他调整

- 简化标签栏的新建 tab 按钮。
- 取消 RPC 等待时及时移除 pending 注册，避免遗留未完成请求。
- 大段粘贴集成测试改为等待 shell／接收程序真正就绪，去掉依赖固定延时的竞态。
- 所有变更按功能保留独立提交，不合并为一个 squash commit。

## 验证与限制

发布验证包含 195 个 Windows release 单元测试、4 个隔离 zoxide 历史库测试、1 个 pi 同步重绘回放及 5 个隔离 Rex 的文件传输／会话／终端集成测试。文件传输测试覆盖批量上传、空文件、二进制一致性、取消保护和覆盖行为；不接触用户会话。

- GUI 外观已用 Windows 隔离窗口截图检查；所有输入法、DPI 和原生拖放组合仍需持续实机验收。
- 启动时偶发的 GPUI `RefCell already borrowed` 问题未宣称已修复。
- 服务端自定义 keymap 的部分字母转发、重复键及解绑行为仍有已知限制。
- 安装包未做 Authenticode 签名，Windows 可能提示未知发布者。
