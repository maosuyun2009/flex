# flex 0.0.9

Windows 客户端更新，汇总 0.0.8 之后的改动。

## 下载与安装

- `flex-0.0.9-setup.exe`：Windows x64 当前用户安装包，无需管理员权限。
- `SHA256SUMS.txt`：下载文件校验值。

安装前请关闭 flex 客户端；无需停止 Rex server。安装不会清除已保存的服务器连接和设置。

## 主要更新

### WSL 服务器

- `+` 菜单新增 **This machine's WSL…**：在默认 WSL 发行版里启动 Rex server 并连接。使用镜像网络模式下与 Windows 共享的回环地址 `127.0.0.1:7297`，不需要发行版自身的 IP。
- 点击已保存的 WSL 条目（或它的 Reconnect）时，若端口无响应，会先弹确认框再启动服务器；`Enter` 继续、`Esc` 取消。服务器已在运行但没有 TCP 监听时，`rex server start` 不会追加监听参数，此时会先停止再启动，**这会结束该服务器会话里正在运行的程序**，因此需要确认。

### 快捷键

- `Alt-1`…`Alt-9` 切换到对应 tab（按会话的 window 顺序，越过最后一个 tab 时不动）。
- `Ctrl-Shift-←/→/↑/↓` 改为调整分割尺寸（每次 6%，限制在 8%–92%）；位于窗口边缘的 Pane 没有对应分隔线时，改按背后的分隔线反向移动，因此长大之后可以用相反方向收回。
- tab 移动改为 `Ctrl-Alt-←/→`。`RaiseFloat` / `LowerFloat` 保留为可绑定动作，但不再占用默认按键。

### 中文输入法

- 标点重复：输入法提交的全角标点不再限定为 12 组硬编码对应，改为按 Unicode 区块判断「提交内容是纯全角标点」；`"` → `“`/`”`、`-` → `——`、`~` → `～`、`\` → `、`、`$` → `￥`、`^` → `……` 等此前都会同时留下英文键。
- 多余空格：选词用的空格此前完全没有被记录，现按「紧邻提交、且提交内容不是空格」收回。
- Windows 不保证按键与输入法提交的先后顺序：两种顺序都已处理，按键在前时用 DEL 收回，提交在前时丢弃随后到达的那个键（150ms 时间窗比较，不延迟按键）。
- `FLEX_DEBUG=1` 时输出 `[key] send`、`[ime] commit …`、`[ime] dropped`、`[find] key`，用于定位输入法时序问题。

## 验证

- Windows 全工作区单元测试（80 个）、release 构建及 NSIS 打包。
- 真机验证：`Alt-1`…`Alt-9` 切换 tab、`Ctrl-Shift-方向键` 调整分割、WSL 条目冷启动与「已在运行但无监听」两条路径。
- 中文输入法：上述两类问题经实机确认不再复现。

## 已知限制

- 输入法时序处理仍是启发式：以 150ms 为窗判断「这个键就是输入法刚回答的那个」。若在提交后 150ms 内又按下标点或空格，且该键自身的 keydown 始终没有到达，这一次按键会被丢弃。
- 若先输入一个真实空格、随后用鼠标点选候选词，该空格会被当作选词空格收回。
- 安装包未做 Authenticode 签名，Windows 可能显示未知发布者提示。
- 物理扫描码快捷键、终端图片、完整 OSC 8、任意插件内容渲染及原生系统通知尚未完整支持。

更多实现范围见 `docs/rex-client-coverage.md`，本地 SDK 补丁见 `vendor/shrew/README.md`。
